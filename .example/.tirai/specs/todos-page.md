# Todos page smoke test

## Requirement

The Todos page exposes the form used to add a task.

## Expected behavior

- Navigating to `/todos` displays the task title input.
- The Add button is enabled for a valid page render.

This specification is paired with the canonical TestCase and trusted mapping
under `.tirai/artifacts/` and `.tirai/mappings/` so the example can run without
AI credentials or selector guessing.
