sequenceDiagram
    autonumber
    actor QA as Tester / QA
    participant Skill as Codex Skill
    participant CLI as TIRAI CLI + workflow
    participant AI as Configured AI provider
    participant WS as .tirai workspace
    participant PW as Playwright / Chromium
    participant App as Web app under test

    QA->>Skill: Chọn spec Excel / Markdown / HTML và phạm vi test
    Skill->>CLI: tirai ingest spec, sau đó tirai plan
    CLI->>AI: Trích xuất requirements, scenarios, cases
    AI-->>CLI: Cấu trúc có requirement links và provenance
    CLI->>WS: Lưu source, contract, test plan, TestCases, fingerprints
    Note over CLI,WS: Mặc định black-box. App source chỉ scan read-only khi tester opt-in.

    alt Requirement còn mơ hồ
        Skill-->>QA: Hỏi rõ, case liên quan bị chặn
        QA->>Skill: Trả lời
        Skill->>CLI: tirai review clarify
        CLI->>WS: Sửa generated case, giữ spec/provenance, xóa approval cũ
    else Requirement đã rõ
        Skill-->>QA: Trình bày case để review
    end
    QA->>Skill: Duyệt steps, inputs, expected UI, cleanup chính xác

    Skill->>CLI: Cấu hình target local / dev / staging và secret refs
    opt Đăng nhập SSO thủ công
        Skill->>CLI: tirai auth login
        CLI->>PW: Mở browser headed
        QA->>PW: Đăng nhập thủ công
        PW-->>WS: Lưu session tạm, private, gitignored
        Note over QA,WS: Session bị xóa sau run. Nếu bỏ dở, dùng tirai auth clear.
    end
    Skill->>CLI: tirai web discover
    CLI->>PW: Khám phá same-origin route và navigation an toàn
    PW->>App: Mở route, không submit form hoặc mutate dữ liệu
    App-->>PW: UI và controls hiển thị
    PW-->>CLI: Route/form metadata
    CLI->>WS: Ghi snapshot discovery
    Skill-->>QA: Trình bày routes
    QA->>Skill: Chọn route cho từng case
    Skill->>CLI: tirai review approve case + route
    CLI->>WS: Lưu approval gắn case/spec fingerprints và route

    Note over QA,Skill: Trước MỖI run: xác nhận lại URL, tenant test riêng và đúng case IDs.
    QA->>Skill: Xác nhận môi trường, tenant, selection
    Skill->>CLI: tirai execute chỉ với IDs đã duyệt
    CLI->>WS: Snapshot spec, contract, cases, approvals của run
    loop Mỗi UI case đã chọn và được duyệt
        CLI->>PW: Agentic executor + orchestrator chạy Playwright
        Note over CLI,PW: Cùng origin · infra retry tối đa 1 lần · assertion không retry · mismatch không chặn case độc lập.
        PW->>App: Thực hiện interaction đã duyệt
        App-->>PW: UI result
        PW-->>CLI: Observation thực tế, assertion outcome, sanitized evidence
        opt Case có mutation và cleanup chính xác đã duyệt
            CLI->>PW: Dọn đúng record do test hiện tại tạo
            PW->>App: Thực hiện cleanup hẹp
            App-->>PW: Kết quả cleanup
        end
        alt Cleanup lỗi hoặc ownership không chắc
            CLI-->>Skill: Dừng case phụ thuộc, yêu cầu manual cleanup
        else Cleanup xong hoặc không cần
            CLI-->>Skill: Tiếp tục các case độc lập
        end
    end
    CLI->>AI: Tạo bug-draft candidate và severity proposal
    AI-->>CLI: Candidate + rationale, chưa phải kết luận cuối
    CLI->>WS: Lưu report JSON/MD, snapshot, sanitized evidence
    CLI-->>Skill: Kết quả có spec link, repro, expected / observed
    Skill-->>QA: Trình bày report và bug draft
    QA-->>Skill: Xác nhận severity + wording trước khi chia sẻ

    opt Export TestCases để review/chia sẻ
        Skill->>CLI: tirai export
        CLI->>WS: JSON / XLSX / Markdown / PDF / DOCX
    end
    Note over CLI,WS: Luồng code-gen hiện hữu là nhánh riêng: trusted mappings → Playwright/Vitest → tirai run.
    Note over QA,CLI: Confluence cần export file trong v1. Ngoài phạm vi: API, visual, a11y, performance, production, CI, tracker.
